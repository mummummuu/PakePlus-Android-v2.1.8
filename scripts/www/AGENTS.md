# 班主任模拟器项目文档

## 项目概述

**班主任模拟器**是一个基于 Web 的模拟经营类校园策略游戏。玩家扮演班主任,管理一个班级走过三年高中生活,最终迎接高考的审判。

### 核心玩法

- **游戏周期**: 6个学期 × 10周 = 60周
- **考试系统**: 每学期期中、期末各一次联考，第60周举行高考
- **竞赛系统**: 高二阶段进行学科竞赛(MO/PhO/ChO/BO/OI)，获奖学生在高考中获得优势
- **学生管理**: 管理学生精力、积极性、学习能力和人际关系
- **资源管理**: 平衡班主任精力、血量和工资
- **胜利目标**: 提高班级985/211/一本升学率和平均分
- **随机事件**: 每4周触发2-3个随机事件，包含26种不同类型的突发事件
- **天赋系统**: 学生拥有20种特殊天赋，影响游戏进程
- **多种模式**: 座位表支持普通、关系、状态、竞赛四种显示模式，便于不同管理需求

### 技术栈

这是一个纯前端项目,使用原生 Web 技术开发:

- **HTML5** - 页面结构和布局
- **CSS3** - 样式和动画效果
- **JavaScript (ES6+)** - 游戏逻辑和交互

## 游戏机制详解

### 学生属性系统

每个学生有以下核心属性:

- **学习能力(learnCap)**: 各科学习能力的上限,越高成绩越好
- **精力值(energy)**: 当前精力状态,影响考试发挥(0-100)
- **积极性(enthusiasm)**: 学习动力,影响成绩和状态(15-100)
- **智商(IQ)**: 固定属性,影响学习成长速度
- **性格(character)**: 影响人际关系发展
- **天赋(talents)**: 每个学生拥有0-2个特殊天赋，影响游戏进程

### 天赋系统

游戏包含20种特殊天赋，学生可能随机获得：

**负面天赋**：
- **填缺考标记** - 每次考试各科均有20%概率得0分
- **忘填名字** - 每次考试每科均有5%概率得0分
- **义和团员** - 英语学习能力保持较低
- **林黛玉** - 大幅增加请假概率
- **大烟鬼** - 每回合10%概率抽烟，50%概率恢复50精力，50%概率被劝退
- **阴暗爬行** - 积极性保持较低
- **冷漠** - 不与他人交往，跳过关系处理

**正面天赋**：
- **体育生** - 精力恢复快(1.8倍)，学习能力增长慢(0.3倍)
- **三好学生** - 积极性增长快(2倍)，学习能力增长快(2倍)
- **千里眼** - 每次考前显示自己的排名
- **理科战神** - 理科学习能力保持很高
- **文曲星** - 文科学习能力保持很高
- **铁人** - 不会因精力耗尽而死
- **热情** - 与他人关系只增不减

**特殊天赋**：
- **传奇机长** - 每次考前一星期大幅降低精力(-5)，大幅增加学习能力(3倍，仅限男生)
- **伽罗瓦** - 数学学习能力保持很高
- **爆发** - 每次考试有5%概率各科额外加分
- **暴力** - 每回合有2%概率殴打班主任，扣除班主任3血量
- **弹反** - 无法被劝退；当被劝退时殴打班主任，扣除班主任7点血量
- **海王** - 大概率同时与多人恋爱；恋人迅速变化

### 随机事件系统

游戏包含完整的随机事件系统，每4周触发2-3个事件（跳过考试周）：

**事件类型**：
- **CHOICE** - 选择事件，提供多个选项供玩家选择
- **CONFIRM** - 确认事件，显示单个确认按钮

**事件示例**：
- 学生跑路去机房打游戏
- 学生在厕所抽烟
- 携带MP5进班（危险事件）
- 天花板掉落砸死学生
- 学生偷吃零食
- 学生打架斗殴
- 学生早恋被抓
- 学生生病请假
- 等等...共26种不同事件

**事件效果**：
- 影响班主任精力、血量
- 影响学生精力、积极性、学习能力
- 可能导致学生死亡
- 可能触发特殊事件（如MP5攻击警告）

**控制台调试**：
```javascript
// 在浏览器控制台中触发特定事件
gameClass.triggerSpecificEvent(事件ID);
// 例如：触发天花板掉落事件
gameClass.triggerSpecificEvent(110);
```

### 座位表显示模式

座位表支持四种显示模式，可通过按钮切换:

1. **普通模式** (Normal)
   - 学生方格颜色代表性别
   - 男生：蓝色
   - 女生：粉色
   - 显示学生姓名、学习能力血条、精力血条

2. **关系模式** (Relation)
   - 以当前选中学生为基准
   - 其他学生颜色代表与该学生的关系
   - 关系从好到差：红色(恋人) → 橙色(朋友) → 黄色(较好) → 绿色(普通) → 蓝色(不满) → 紫色(仇恨)
   - 便于快速了解人际关系网络

3. **状态模式** (Status)
   - 显示学生的当前状态
   - 不同颜色代表不同状态
   - 包括：正常、请假、集训、生病等状态

4. **竞赛模式** (Competition)
   - 显示学生的竞赛状态
   - 显示竞赛科目、阶段、奖项信息
   - 便于管理竞赛生

### 关系系统

学生间的关系分为六级:

1. **普通** (Normal) - 默认状态
2. **较好** (Better) - 关系不错
3. **朋友** (Friend) - 互帮互助,加精力和积极性
4. **恋人** (Loving) - 恋爱关系,可能触发特殊事件
5. **不满** (Disliking) - 关系不好
6. **仇恨** (Hating) - 互相影响,减精力和积极性

座位邻座的关系影响最强。

**关系影响**：
- 朋友关系：精力+0.6，积极性衰减-0.3
- 仇恨关系：精力-0.4，积极性衰减+0.3
- 恋人关系：60%概率精力+0.4，40%概率精力-0.4

### 竞赛系统

游戏包含完整的学科竞赛系统，仅在高二阶段(第3-4学期)进行:

**竞赛类型**:
- **数学竞赛 (MO)** - Math Olympiad
- **物理竞赛 (PhO)** - Physics Olympiad
- **化学竞赛 (ChO)** - Chemistry Olympiad
- **生物竞赛 (BO)** - Biology Olympiad
- **信息学竞赛 (OI)** - Olympiad in Informatics

**竞赛阶段**:
- **联赛** - 省级联赛，进入省队概率40%
- **国赛** - 全国决赛

**奖项设置**:
- 金牌 - 国赛5%概率
- 银牌 - 国赛10%概率
- 铜牌 - 国赛15%概率
- 无奖 - 其余情况

**时间安排**:
- 第31周: 化学国赛、数学联赛
- 第32周: 物理联赛
- 第33周: 数学国赛、物理国赛
- 第34周: 信息学联赛
- 第43周: 生物联赛
- 第50周: 生物国赛、信息学国赛

**竞赛生**:
- 简单模式下20%的学生被选为竞赛生
- 集训期间学习能力会衰减
- 获奖学生在高考录取时获得优势

### 班主任操作

班主任可以执行以下操作:

- **约谈学生** - 提升学生积极性(消耗20精力)
- **请学生吃饭** - 恢复学生精力(单个350元/全班2000元)
- **调教学生** - 消耗300元、30精力，80%概率重置学生天赋(高风险高回报)
- **随机重排座位** - 打散不良关系
- **交换座位** - 手动调整学生位置
- **组织活动** - 提升全班状态(消耗40精力，多种活动类型)
  - 🏃‍♂️ 运动会 - 提升全体精力和积极性
  - 🎬 看电影 - 放松身心，恢复精力
  - 🌸 春游踏青 - 增进感情，改善关系
  - 🎤 才艺展示 - 提升自信和积极性
  - 📚 集体自习 - 提升学习能力
  - 🧺 野餐聚会 - 提升班级凝聚力
  - 🎮 游戏之夜 - 放松心情
  - 🤝 志愿服务 - 提升品格和积极性
- **召开班会** - 班级管理(消耗40精力，消耗500元，多种班会类型)
  - 🍲 鸡汤班会 - 提升全体积极性
  - 😠 恐吓班会 - 提升积极性但可能降低精力
  - 🏆 表彰班会 - 奖励优秀学生
  - 🎲 自由班会 - 随机效果
  - 💬 吐槽大会 - 释放压力，恢复精力
  - 🎁 惊喜班会 - 大幅提升积极性
- **挑拨离间** - 破坏学生关系(高风险操作，成功后可能降低血量)
- **购买药品** - 恢复班主任血量(500元/5点)
- **劝退学生** - 移除表现差的学生
- **查看请假** - 处理学生请假申请(可设置自动处理)
- **保存游戏** - 保存当前游戏状态为JSON文件
- **加载游戏** - 从JSON文件恢复游戏状态

### 失败条件

游戏失败的条件:

1. 班主任血量归零(精力低于20时每周扣5点)
2. 全班学生死亡(被劝退)

### 胜利目标

游戏结束后,根据以下指标评定:

- 985录取率
- 211录取率
- 一本录取率
- 班级平均分

评级从"不合格"到"特级教师"共多个等级。

### 添加新的随机事件

在 `RANDOM_EVENTS` 数组中添加新事件：

```javascript
{
    id: 999,  // 唯一ID
    type: RandomEventType.CHOICE,  // 或 RandomEventType.CONFIRM
    template: '{student}发生了某种事情',
    options: [
        {
            text: '选项1',
            effect: 'energy:+5, enthusiasm:-3'
        },
        {
            text: '选项2',
            effect: 'energy:-5, enthusiasm:+3'
        }
    ]
}
```

支持的效果类型：
- `energy:±数值` - 班主任精力变化
- `enthusiasm:±数值` - 学生积极性变化
- `learnCap:±数值` - 学生学习能力变化
- `student:kill` - 学生死亡
- `teacher:hurt:±数值` - 班主任血量变化
- `teacher:kill` - 班主任死亡

## 已知问题和限制

1. **大班级性能**: 学生人数超过80时，座位表渲染可能有性能问题
2. **本地存储限制**: 浏览器 localStorage 限制约5MB，大存档可能无法保存
3. **移动端适配**: 虽然支持移动端，但操作体验不如桌面端
4. **学生人数限制**: 当前仅提供18/27/36/45/54人选项，理论上可支持更多但未测试
5. **竞赛生比例**: 竞赛生比例固定为20%，无法自定义
6. **座位表布局**: 9列固定布局，小班级可能显示空白座位
7. **精力平衡**: 不主动操作时学生死亡率约为20%，已优化但仍有随机性
